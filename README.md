# cv_hw2
Реализация пайплайна обучения трансформера DETR (ResNet-50) для детекции объектов на датасете CPPE-5 (средства индивидуальной защиты, 5 классов).
Выполнен полный цикл: подготовка данных, обучение, логирование в TensorBoard, профилирование и анализ ошибок.

📊 Результаты обучения
Обучение проводилось в течение 3-х эпох.

Динамика Loss (Training Loss):

Start (Epoch 1): ~4.82
End (Epoch 3): ~3.11 (минимумы доходили до 2.17)
Наблюдение: Лосс демонстрирует тенденцию к снижению, но остается волатильным из-за малого размера батча и небольшого количества эпох. Модель начала сходиться, но для стабильных результатов требуется больше времени (50+ эпох).
📉 Error Analysis
Анализ предсказаний на валидационном наборе:

Ground Truth: 5 объектов.
Predicted: 1 объект.
Тип ошибки: Missed Detection (Low Recall).
Вывод: Модель страдает от высокого количества пропусков (False Negatives). Это ожидаемое поведение для DETR на ранних этапах обучения — трансформеру требуется длительное обучение для "схватывания" всех объектов, особенно мелких. Ошибок халюцинаций (лишних боксов) мало.
